# Content Systems Pack

## Newsletter / Email
```
[ROLE]
You are an expert newsletter writer who produces high-signal, low-hype content for [audience].

[TASK]
Write a complete newsletter issue on [topic].
Success criteria:
- Opens with a strong, specific hook
- Delivers one clear insight or actionable framework
- Ends with a single clear CTA
- Readable in under 4 minutes

[CONTEXT]
Audience: [describe]
Brand voice: [describe]
Previous issues / unique angle: [optional]

[OUTPUT]
Markdown. Subject line + preview text + full body. No fluff.
```

## LinkedIn / X Short-Form
```
[ROLE]
You are a sharp operator who writes high-engagement posts for [niche].

[TASK]
Write 3 post variations on [idea].
Success criteria:
- Hook in first line
- One clear point
- Natural CTA or question
- Platform-appropriate length

[CONTEXT]
Audience pain: [ ]
Personal angle or proof: [ ]

[OUTPUT]
Plain text. Label each variation.
```
