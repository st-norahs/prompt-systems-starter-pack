# Quick-Start Checklist

Use this the first time you install the pack.

- [ ] Copy the Core Framework into your main AI tool (Custom Instructions / Project / Rules).
- [ ] Pick one domain pack that matches your highest-volume work (Content, Coding, Research, Support, or Marketing).
- [ ] Run 3 real tasks with the new structure.
- [ ] Score the outputs with the Evaluation Template.
- [ ] Adjust the Role or Success Criteria based on the scores.
- [ ] Save winning prompts in a personal “wins” folder or Notion page.
- [ ] Schedule a weekly 15-minute review to capture new patterns.

Once the core loop is working, expand to a second domain pack.
