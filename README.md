# Prompt Systems Starter Pack

Production-ready prompt systems for content, coding, research, support and marketing.

**Version:** 1.0  
**Last updated:** 2026-09-24  
**License:** Personal & commercial use allowed. Redistribution of the pack itself requires written permission.

## What’s Included

1. **Core Framework** – Role → Task + Success Criteria → Context → Output Format + Constraints
2. **Domain Packs**
   - Content Systems (newsletters, LinkedIn, X, blog)
   - Coding & Technical
   - Research & Analysis
   - Customer Support
   - Marketing & Sales
3. **Evaluation Template** – Simple rubric to test and improve any prompt
4. **Model Adaptation Notes** – Quick adjustments for major model families
5. **Quick-Start Checklist**

## How to Use

1. Copy the relevant system prompt into your AI tool (Claude Projects, ChatGPT Custom Instructions, Cursor rules, etc.).
2. Fill the variable sections with your specific context.
3. Run the Evaluation Template after the first few outputs and iterate.
4. Keep a personal “wins” log of prompts that consistently perform.
